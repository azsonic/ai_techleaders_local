# Content and messages

The product's words are short, direct and respectful. A message names the action, the outcome and the next step, and warmth comes from being helpful, not from decoration (P10.1, C02). All examples below are strings the system already uses. The product language is American English (see Spelling below).

## What the product says, and what it does not

| It says (three examples)                                                                                                      | It does not say                                                                                                                                      |
| ----------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| **"Message wasn't sent. Try again."** What happened and what to do (P10.1, P12.2).                                            | **"Oops! Something went wrong."** It says nothing about what happened or what to do (AC01, AC03, P10.1).                                             |
| **"Full refund due: 120 PLN."** and **"No refund. The mentor is paid."** The money outcome in words, amount first (R09, R15). | **"Are you sure?"** with "OK" and "Cancel". The question must name the object and the buttons must name the actions (Deletion confirmation pattern). |
| **"Nothing was charged."** when a booking could not be made: the person's first worry, answered (R06, E02 spec).              | **"Boost your career ✨"** or **"Rated 4.9 ★"**. Decoration, sparkles and ratings are rejected (A01.3, R02.5, N02).                                  |

## Buttons: a verb and an object

A button says what will happen. Never "OK", "Submit", "Yes" or "Confirm".

| Use                                                             | Not                                               |
| --------------------------------------------------------------- | ------------------------------------------------- |
| Book session for 120 PLN, Pay 120 PLN and book                  | Submit, Continue                                  |
| Send message, Send answer                                       | OK, Send                                          |
| Cancel session, Suspend mentor, Revoke invitation               | Yes, Confirm                                      |
| Keep session, Keep as it is (the safe choice, first in the DOM) | No, Cancel (when it is unclear what is cancelled) |
| Try again                                                       | Retry (a developer's word)                        |

While the server works, the button keeps the verb in the present: "Booking…", "Paying…", "Suspending…" (P12.1).

## Errors: what happened and what to do

An error says what happened, what is safe and what to do. It never blames the person and never loses their entries.

| Case                         | Message                                                                                     | Source                |
| ---------------------------- | ------------------------------------------------------------------------------------------- | --------------------- |
| The server broke             | "Something broke on our side. Try again in a minute."                                       | P10.1, P12.2          |
| No answer from the server    | "The server did not answer. Check your connection and try again. What you entered is kept." | P12.2                 |
| The slot was taken           | "This slot was taken a moment ago. Nothing was charged. Choose another slot."               | R06                   |
| The card was declined        | "Your card was declined. Nothing was charged. Use another card."                            | P12.2 (proposal, E03) |
| A field is empty             | "Write your question so the mentor can prepare." (names the field and why)                  | WCAG 3.3.3            |
| A required choice is missing | "Choose an answer."                                                                         | WCAG 3.3.1            |
| A message did not send       | "Message wasn't sent." with the button "Try again"                                          | P12.2                 |

## Spelling and the product's words

American English: favorites, color, behavior. One exception: the status words approved in stage 3 keep their wording ("Cancelled by you", "Cancelled by mentor") because they are the state machine's own words. Amounts keep the currency code (`PLN`), never "zloty" in the interface. The product word for a mentor's technology is **Stack** (D07): a request that says "technology" means stacks, and filters use the four stacks the system has.

## Toast messages

A toast confirms a small thing the server accepted. The title names the object and the outcome; one short sentence says the next step. Never an error.

| Case                       | Title                                      | Sentence                                             |
| -------------------------- | ------------------------------------------ | ---------------------------------------------------- |
| A mentor removed from favorites | "Anna Kowalska removed from favorites"  | "You can save this mentor again from their profile." |
| Availability saved         | "Availability saved"                       | "Mentees see the new windows now."                   |

## Removing something: failure wording

Pattern: the title names the object ("The mentor was not removed"), then comes the server's message, then a sentence saying the object is still in the list ("They are still in your favorites.").

| Case                      | Alert text                                                                                              |
| ------------------------- | ------------------------------------------------------------------------------------------------------- |
| The server broke          | The server's message, then "They are still in your favorites."                                          |
| No answer from the server | "The server did not answer. Check your connection and try again." then "They are still in your favorites." |

## A mentor's headline

One line about the mentor's work, written by the mentor: at most 200 characters (confirmed by the Product owner). It wraps and is never cut with an ellipsis. A mentor without one shows nothing in its place.

## Statuses

Statuses are words from the state machine, worded for who is looking (approved in stage 3): Pending, Confirmed, Cancelled by you, Cancelled by mentor (a mentor sees "Cancelled by mentee" and "Cancelled by you"), Completed, and two attendance words: the mentee sees "You did not attend" and "Mentor did not attend", the mentor sees "Mentee did not attend" and "You did not attend". These replace the single word "No-show" (owner decision, 2026-10-28), and the Outcome filter on a Past tab uses the same words as the badge. Invitations: Pending, Accepted, Expired, Revoked. Payouts (proposal): Held, Paid, Refunded, In dispute. Gate (proposal): Closed, Open, Stopped.
