# Components

Every component in the system with a small working preview, its group, one sentence on what it does and where to read more. The previews are the real components; use the controls on each documentation page to change them. To choose between two components, go to [How to choose](?path=/docs/design-system-how-to-choose--docs).

**Base components** are the shadcn `base-nova` components (built on Base UI, not Radix) adapted to the product's tokens. Each has a documentation page with 13 sections and a state matrix. **Product components** are built only from base components for one epic; their stories show the data states (loading, empty, error, partial data, lots of data, long text). E03, E04 and E05 have no specification yet: their components are proposals.
