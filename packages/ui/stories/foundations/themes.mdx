# Themes

DevMentor has a light and a dark theme. Both define every semantic token and both pass the contrast table on the Color page.

- Light is the default, defined on `:root` in `src/styles/tokens.css`.
- Dark redefines only the tokens that change, under `.dark`.
- The theme switch in the Storybook toolbar adds or removes `dark` on `<html>`. Dialogs, menus and popovers render outside the story, so they receive the theme from the root too.

## Rules

| Rule                                                                                                       | Source                            |
| ---------------------------------------------------------------------------------------------------------- | --------------------------------- |
| Define a token in both themes at once.                                                                     | tokens.md contract                |
| Recalculate contrast for every changed pair before saving.                                                 | tokens.md contract                |
| Components never branch on theme (`dark:` classes with colors). The token changes, the component does not. | Rule 3 of the design system brief |
