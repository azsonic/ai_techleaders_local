# Separator

## 1. Purpose

Draws the thin line that separates adjacent rows or groups, so a dense list stays readable.

## 2. When to use

- Between booking rows, mentor rows and invitation rows (R01.3).
- Between inline items such as page tabs, with the vertical orientation.

## 3. When not to use

| Situation                      | Use instead                                |
| ------------------------------ | ------------------------------------------ |
| Separating cards from the page | A 1px border on the card (shape and depth) |
| More space between sections    | Spacing (`--space-section`), not a line    |
| Hiding the lack of structure   | Group content with a heading               |

## 6. States

Static component. It has no hover, focus, pressed, disabled, loading, selected or error state.

## 7. Behavior and accessibility

- Role `separator` with `aria-orientation`. Not focusable.
- Use it only where the separation carries meaning. Purely visual lines on a list are exposed as extra stops for screen readers; keep them few.
- The line is `--border`, 4.41:1 light and 7.63:1 dark against the page (WCAG 1.4.11).

<Canvas of={Stories.ExposesItsOrientation} />

## 8. Content

Not applicable: the separator has no text.

## 9. Responsiveness

- A horizontal separator fills the width of its container at every width. A vertical one needs a container with a height.

## 11. Code

```tsx
<ul>
  {bookings.map((booking, index) => (
    <li key={booking.id}>
      {index > 0 && <Separator />}
      <BookingRow booking={booking} />
    </li>
  ))}
</ul>
```
