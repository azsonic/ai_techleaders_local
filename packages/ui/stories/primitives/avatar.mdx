# Avatar

## 1. Purpose

Marks who a message or a card belongs to, so people can follow who said what.

## 2. When to use

- Next to the author and time of a message in a session (R02.3).
- On a mentor card or profile beside the display name.

Where it appears is a **proposal**: the brief does not mention mentor photos. The Product owner approved adding an avatar on 2026-10-25 and left its use to this system.

## 3. When not to use

| Situation                   | Use instead                                               |
| --------------------------- | --------------------------------------------------------- |
| A rating or a trust signal  | Public-work links and experience text (N02)               |
| Decoration, or an AI symbol | Nothing (R02.5, A01.3)                                    |
| A status                    | [Status badge](?path=/docs/primitives-status-badge--docs) |

## 6. States

Static component. It has no hover, focus, pressed, disabled, loading or error state. It shows **image** or **initials**.

| State                       | Behavior                                             | Source |
| --------------------------- | ---------------------------------------------------- | ------ |
| Image loaded                | The image fills the square.                          | n/a    |
| No image, loading or failed | Initials on a muted fill. Never a broken image icon. | n/a    |

## 7. Behavior and accessibility

- Not interactive, not focusable. If it must be clickable, wrap it in a link or button with a name.
- The avatar is an image named by the person's name. When the name is written next to it, set `decorative` so screen readers do not read it twice.
- Initials against the muted fill measure 13.92:1 light (WCAG 1.4.3).

## 8. Content

- Initials come from the first and last word of the name ("Anna Kowalska" gives AK). A single name gives its first two letters. Empty gives "?".
- Never show a different name than the one beside it.

## 9. Responsiveness

- Fixed sizes. At 320px, keep the name to the right and let it wrap; the avatar does not shrink.
