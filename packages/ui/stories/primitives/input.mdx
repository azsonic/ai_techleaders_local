# Text input

## 1. Purpose

Lets a person type one short line, such as a name, a price or a link.

## 2. When to use

- Display name, price for 25 or 50 minutes, link to public work, e-mail on sign-in.
- Search and filter fields in a list (use `density="dense"`).

## 3. When not to use

| Situation                                     | Use instead                                                              |
| --------------------------------------------- | ------------------------------------------------------------------------ |
| Several lines (the question to the mentor)    | [Textarea](?path=/docs/primitives-textarea--docs)                        |
| Choose one of a few known values (start time) | [Select](?path=/docs/primitives-select--docs) or a radio group (batch 2) |
| A yes or no choice                            | Checkbox or switch (batch 2)                                             |

Sources: brief E02 spec (question up to 2,000 characters is multiline), WAI-ARIA Authoring Practices.

## 6. States

<Canvas of={Stories.StateMatrixStory} />

| State                      | Behavior                                                                             | Source                |
| -------------------------- | ------------------------------------------------------------------------------------ | --------------------- |
| Hover                      | Border darkens to `--foreground`.                                                    | R01.5                 |
| Focus                      | 2px ring in `--ring`, offset 2px.                                                    | tokens.md, WCAG 2.4.7 |
| Disabled                   | `--muted` fill, muted text. Say why in the hint.                                     | WCAG 3.3.2            |
| Error                      | Border in `--destructive`, an error message below (not color alone), `aria-invalid`. | WCAG 1.4.1, 3.3.1     |
| Pressed, loading, selected | Not applicable to a text field.                                                      | —                     |

## 7. Behavior and accessibility

- Keyboard: Tab focuses, typing edits. Native `input` role (`textbox`, `searchbox`, `spinbutton` by `type`).
- Inside a Form field the label, hint and error are connected automatically (`aria-describedby`, `aria-invalid`).
- Validate when the person leaves the field and on submit, not on every key (pattern: form, stage 3).
- Border contrast at least 3:1 (WCAG 1.4.11): measured 4.41:1 light and 7.63:1 dark.
- Height at least 24px (WCAG 2.5.8).

## 8. Content

- Label: a noun, 1 to 4 words ("Display name"). Placeholder: a realistic example ("Anna Kowalska").
- Numbers: write the unit in the label ("Price for 25 minutes (PLN)").
- Long values scroll inside the field; do not shrink the text.

<Canvas of={Stories.LongContentNarrow} />

## 9. Responsiveness

- 320px: full width. 768px and 1440px: forms use `max-w-prose` or a fixed column; fields never stretch across the whole page.
- Text stays 16px at default density, so mobile browsers do not zoom on focus.
