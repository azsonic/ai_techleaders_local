# Button

## 1. Purpose

Lets a person start one clear action, such as booking a slot or cancelling a booking.

## 2. When to use

- Submit a form: "Book 25 minutes", "Save profile", "Send invitation".
- Confirm in a dialog: "Cancel booking", "Revoke invitation".
- Start a step that changes data or opens the session: "Open session".

## 3. When not to use

| Situation                                                 | Use instead                                                                    |
| --------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Go to another page (mentor profile, My bookings)          | [Text link](?path=/docs/primitives-text-link--docs) (a button never navigates) |
| An action inside a sentence or a table cell, low priority | Text action (`variant="link"`)                                                 |
| Many actions on one row                                   | An action menu (batch 4)                                                       |
| An icon alone with no label                               | An icon button with an `aria-label` and a tooltip                              |

Sources: WAI-ARIA Authoring Practices (button vs link), R02.5 (text labels, no decoration).

## 5. Variants

<Canvas of={Stories.Variants} />

| Variant       | Choose it when                                                      | Source             |
| ------------- | ------------------------------------------------------------------- | ------------------ |
| `default`     | The one main action of the view. At most one per view.              | R01.5              |
| `secondary`   | A supporting action beside the main one. It has a visible border.   | R01.5, WCAG 1.4.11 |
| `ghost`       | A low-priority action with no border, such as "Show details".       | R01.5              |
| `destructive` | The action cannot be undone or cancels something paid. Opaque fill. | P12.1, P12.2       |
| `link`        | A text action that is not navigation. Always underlined.            | tokens.md          |

Sizes:

<Canvas of={Stories.Sizes} />

- `default` 40px for forms, booking and conversation (R02.1). `dense` 32px for browsing rows and tables (R01.1, P03). `xs` 24px is the smallest click target allowed (WCAG 2.5.8). Icon sizes match.
- Radii, heights and padding are approved decisions for this product (stage 2), not the library default.

## 6. States

<Canvas of={Stories.StateMatrixStory} />

| State    | Behavior                                                                                                                                                                       | Source                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| Hover    | Opaque fill change (`--primary-hover`, `--destructive-hover`) or a darker border. No opacity.                                                                                  | R01.5, P11.1                                                  |
| Focus    | 2px ring in `--ring`, offset 2px. One appearance for the whole system.                                                                                                         | tokens.md, WCAG 2.4.7                                         |
| Pressed  | Same as hover. The button does not move.                                                                                                                                       | P11.1                                                         |
| Disabled | `--muted` fill, muted text, border. Never opacity. **The reason must be written next to the button** and referenced with `aria-describedby`, for example "Booking opens soon". | WCAG 3.3.2, proposal approved 2026-10-25                      |
| Loading  | Label is kept or replaced ("Saving…"). `aria-busy`, repeat activation blocked, still focusable. No spinner (P11.1).                                                            | P11.1, brief: the booking submit disables while the hold runs |

## 7. Behavior and accessibility

- Keyboard: Tab to focus, Enter and Space activate. Focus order follows the reading order.
- Role: native `button`. Do not put `onClick` on a `div` (WAI-ARIA).
- A busy button announces `aria-busy="true"`. Pointer events are off while busy and the keyboard is blocked in code.
- Click target at least 24 × 24px (WCAG 2.5.8). Default and dense sizes are 40 and 32px.
- Icon-only buttons need an accessible name (WCAG 4.1.2).

## 8. Content

- Verb and object: "Book 25 minutes", "Cancel booking", "Revoke invitation". Never "OK", "Submit" or "Yes".
- Aim for 2 to 4 words (about 24 characters). Longer labels wrap in narrow layouts; use `whitespace-normal` with a minimum height.
- Do not include prices or times that can change after load in the label. Show them beside the button.
- Longer languages grow about 30%: leave room instead of fixing a width.

## 9. Responsiveness

- 320px: buttons in a form span the full width (`w-full`). Labels wrap. (Proposal, no reference source.)
- 768px and 1440px: buttons keep their natural width and sit in a row, main action first.
- Heights do not change with width.

## 10. API

<ArgTypes
  of={Stories.Playground}
  include={["variant", "size", "loading", "loadingLabel", "disabled"]}
/>

All native button props are also accepted (`type`, `onClick`, `aria-describedby` and others). The component is a Base UI button; see the technical note in Contributing for the origin of the base.

### An action on one item of a list

Use `variant="secondary"` with `size="dense"`, last inside the card. The `destructive` variant is only for an action that cannot be undone (cancel a booking, suspend a mentor). Removing a favorite is undoable, so it is `secondary`. When the same label repeats on every row, add the object in visually hidden text (see Usage and accessibility).

## 11. Code

Minimal:

```tsx
import { Button } from "@devmentor/ui/components/ui/button";

<Button>Book 25 minutes</Button>;
```

From the booking page: submit while the hold runs, and a visible reason when booking is closed.

```tsx
<Button type="submit" loading={holding} loadingLabel="Booking…">
  Book 25 minutes
</Button>

<Button disabled aria-describedby="closed-note">Book 25 minutes</Button>
<p id="closed-note">Booking opens soon.</p>
```

To style a link as a button, use `<Link className={cn(buttonVariants())}>`. Always wrap `buttonVariants` in `cn()`.
